# The Silver decomp

Silver is the `_SILVER` half of pret/pokegold. There is no separate disassembly
tree at `gs/data.SourceRevision`. Use `docs/POKEGOLD.md` and `pokegold/`.

Version-exclusive wild slots and a few items differ; map headers, warps,
connections, species order, text encoding, moves, evolutions, TMs/HMs, and
mart structure are shared. `gs/rom` locates those tables in whichever
cartridge is loaded.
