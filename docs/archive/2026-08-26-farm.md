# PokePilot Farm Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let N `cmd/pokepilot` processes lease a run spec from a `cmd/pokewall` orchestrator, run it, and report the result — while `POKEPILOT_ORCH_URL` unset keeps today's CLI byte-for-byte unchanged.

**Architecture:** A new dependency-free `farm` package holds the wire types (`Spec`, `Heartbeat`, `FinishReport`) and the runner's small HTTP client. `cmd/pokepilot` gains one code path, gated on `POKEPILOT_ORCH_URL`, that loops lease → apply spec → run → heartbeat → finish, reusing the boot snapshot instead of relaunching the process. `cmd/pokewall` is a second binary in the same module: an in-memory tile registry behind `/v1/lease`, `/v1/runs/{id}/heartbeat`, `/v1/runs/{id}/finish`, and a plain HTML grid page. `emu/`, `skill/`, `agent/`, `red/` gain no import of `farm`; the only touch to an existing package is exposing the trace ring buffer's snapshot (already collected, not yet exported) for the finish dump.

**Tech Stack:** Go 1.26 stdlib only (`net/http`, `encoding/json`, `context`, `time`). No new module dependency. No Docker SDK in the runner.

**Spec:** `docs/archive/2026-08-26-farm-design.md`

## Global Constraints

- Unset `POKEPILOT_ORCH_URL` → `make run`, `go test ./...`, and every existing flag behave exactly as before (design §1.1).
- No Docker API and no Swarm awareness inside `cmd/pokepilot` (design §1.2, §2).
- `cmd/pokepilot` (runner) and `cmd/pokewall` (orchestrator) live in this one repo; no second module (design §1.3, §6).
- `emu/`, `skill/`, `agent/`, `red/` must not import `farm` (design header).
- Spec fields mirror existing flags verbatim: `run_id, seed, planner, starter, dest, fps, max_rounds, max_frames` (design §4).
- Finish dump reuses the bundle already specified in `docs/DESIGN.md` §3.10 (state, trace, save state, last frame), shipped to the wall instead of only left on disk (design §4).

```go
// Package farm holds the wire contract between a pokepilot runner and the
// pokewall orchestrator: lease/heartbeat/finish JSON, and (in client.go)
// the small HTTP client the runner uses to speak it. Nothing here reaches
// into emu, skill, agent, or red — those packages import nothing from
// farm, and farm imports nothing from them.
package farm

// Spec is one run's configuration, filled either by CLI flags (today) or
// by a lease from the wall (farm mode). Field names mirror the flags in
// cmd/pokepilot/main.go one for one.
type Spec struct {
	RunID     string `json:"run_id"`
	Seed      int64  `json:"seed"`
	Planner   string `json:"planner"`
	Starter   string `json:"starter"`
	Dest      string `json:"dest"`
	FPS       int    `json:"fps"`
	MaxRounds int    `json:"max_rounds"`
	MaxFrames int    `json:"max_frames"`
}

// Heartbeat is the small, frequent status push a runner sends while a
// leased run is in progress.
type Heartbeat struct {
	RunID     string `json:"run_id"`
	Frame     uint64 `json:"frame"`
	Map       uint8  `json:"map"`
	X         uint8  `json:"x"`
	Y         uint8  `json:"y"`
	Trace     string `json:"trace"`      // last trace line, for the tile card
	StopSoFar string `json:"stop_so_far"` // human-readable progress note
}

// HeartbeatReply is the wall's answer to a heartbeat. Cancel asks the
// runner to finish the current run at its next natural boundary and lease
// again; it is not a kill signal (design §4, "Stop a run").
type HeartbeatReply struct {
	Cancel bool `json:"cancel"`
}

// FinishReport is why a run ended, sent once when it stops. It is the
// docs/DESIGN.md §3.10 failure bundle, shipped over the wire instead of
// only left on local disk.
type FinishReport struct {
	RunID      string `json:"run_id"`
	Reason     string `json:"reason"` // "stuck" / "error" / "budget" / "done"
	Detail     string `json:"detail"` // last error or stop detail, if any
	TraceTail  []string `json:"trace_tail"`
	SaveState  []byte `json:"save_state"`
	FramePNG   []byte `json:"frame_png,omitempty"`
}
```

```go
package farm

import (
	"bytes"
	"context"
	"encoding/json"
	"fmt"
	"net/http"
)

// Client is the runner's only knowledge of the wall: three HTTP calls.
// No Docker, no Swarm — design §1.2.
type Client struct {
	BaseURL string
	HTTP    *http.Client
}

// NewClient builds a Client with a default *http.Client.
func NewClient(baseURL string) *Client {
	return &Client{BaseURL: baseURL, HTTP: http.DefaultClient}
}

// Lease asks the wall for the next spec. A 204 response means none is
// ready yet; Lease returns (nil, nil) so the caller can wait and retry.
func (c *Client) Lease(ctx context.Context) (*Spec, error) {
	req, err := http.NewRequestWithContext(ctx, http.MethodPost, c.BaseURL+"/v1/lease", nil)
	if err != nil {
		return nil, err
	}
	resp, err := c.HTTP.Do(req)
	if err != nil {
		return nil, fmt.Errorf("farm: lease: %w", err)
	}
	defer resp.Body.Close()
	if resp.StatusCode == http.StatusNoContent {
		return nil, nil
	}
	if resp.StatusCode != http.StatusOK {
		return nil, fmt.Errorf("farm: lease: status %d", resp.StatusCode)
	}
	var spec Spec
	if err := json.NewDecoder(resp.Body).Decode(&spec); err != nil {
		return nil, fmt.Errorf("farm: lease: decode: %w", err)
	}
	return &spec, nil
}

// Heartbeat reports progress for an in-flight run and returns the wall's
// reply, which may ask for a cooperative cancel.
func (c *Client) Heartbeat(ctx context.Context, hb Heartbeat) (HeartbeatReply, error) {
	var reply HeartbeatReply
	body, err := json.Marshal(hb)
	if err != nil {
		return reply, err
	}
	url := fmt.Sprintf("%s/v1/runs/%s/heartbeat", c.BaseURL, hb.RunID)
	req, err := http.NewRequestWithContext(ctx, http.MethodPost, url, bytes.NewReader(body))
	if err != nil {
		return reply, err
	}
	req.Header.Set("Content-Type", "application/json")
	resp, err := c.HTTP.Do(req)
	if err != nil {
		return reply, fmt.Errorf("farm: heartbeat: %w", err)
	}
	defer resp.Body.Close()
	if resp.StatusCode != http.StatusOK {
		return reply, fmt.Errorf("farm: heartbeat: status %d", resp.StatusCode)
	}
	if err := json.NewDecoder(resp.Body).Decode(&reply); err != nil {
		return reply, fmt.Errorf("farm: heartbeat: decode: %w", err)
	}
	return reply, nil
}

// Finish reports why a leased run ended. It is the last call the runner
// makes before leasing again.
func (c *Client) Finish(ctx context.Context, report FinishReport) error {
	body, err := json.Marshal(report)
	if err != nil {
		return err
	}
	url := fmt.Sprintf("%s/v1/runs/%s/finish", c.BaseURL, report.RunID)
	req, err := http.NewRequestWithContext(ctx, http.MethodPost, url, bytes.NewReader(body))
	if err != nil {
		return err
	}
	req.Header.Set("Content-Type", "application/json")
	resp, err := c.HTTP.Do(req)
	if err != nil {
		return fmt.Errorf("farm: finish: %w", err)
	}
	defer resp.Body.Close()
	if resp.StatusCode != http.StatusOK {
		return fmt.Errorf("farm: finish: status %d", resp.StatusCode)
	}
	return nil
}
```

```go
// TraceTail returns the last n trace lines as "kind: text", newest last.
// Used to fill the trace_tail field of a farm.FinishReport; nothing in
// emu imports farm, this just exposes data already collected.
func (m *Emu) TraceTail(n int) []string {
	entries := m.trace.snapshot()
	if n > len(entries) {
		n = len(entries)
	}
	entries = entries[len(entries)-n:]
	out := make([]string, len(entries))
	for i, e := range entries {
		out[i] = e.Kind + ": " + e.Text
	}
	return out
}
```

- [ ] **Step 3: Implement `applySpec` and `runFarm`**

```go
// applySpec turns a leased farm.Spec into the same values -planner,
// -starter, -goto, -fps, -max-rounds and -max-frames already produce from
// flags. A zero MaxRounds/MaxFrames means "use this binary's own
// defaults", never "unlimited" — agent.Run already refuses a zero budget.
func applySpec(s farm.Spec) (planner, starter, dest string, fps, maxRounds, maxFrames int) {
	maxRounds, maxFrames = llmMaxRounds, llmMaxFrames
	if s.MaxRounds > 0 {
		maxRounds = s.MaxRounds
	}
	if s.MaxFrames > 0 {
		maxFrames = s.MaxFrames
	}
	return s.Planner, s.Starter, s.Dest, s.FPS, maxRounds, maxFrames
}

// runFarm is the loop entered when POKEPILOT_ORCH_URL is set: lease,
// apply, run, heartbeat, finish, lease again. bootState is a save state
// taken right after BootToOverworld so each leased run starts fresh
// without relaunching the process (design §1, "the game stays a plain
// process").
func runFarm(m *emu.Emu, client *farm.Client, bootState []byte) {
	ctx := context.Background()
	for {
		spec, err := client.Lease(ctx)
		if err != nil {
			log.Printf("farm: lease: %v", err)
			time.Sleep(5 * time.Second)
			continue
		}
		if spec == nil {
			time.Sleep(2 * time.Second)
			continue
		}
		runOne(m, client, bootState, *spec)
	}
}

// runOne executes exactly one leased spec and reports its finish.
func runOne(m *emu.Emu, client *farm.Client, bootState []byte, spec farm.Spec) {
	if err := m.LoadState(bootState); err != nil {
		log.Printf("farm: run %s: load boot state: %v", spec.RunID, err)
		return
	}
	if spec.Seed != 0 {
		burn := rand.New(rand.NewPCG(uint64(spec.Seed), 0)).IntN(600)
		m.StepFrames(burn)
	}

	plannerName, starter, dest, fps, maxRounds, maxFrames := applySpec(spec)
	m.Pace(fps)

	cancel := make(chan struct{})
	stopHeartbeat := make(chan struct{})
	go heartbeatLoop(m, client, spec.RunID, cancel, stopHeartbeat)
	defer close(stopHeartbeat)

	reason, detail := runSpecOnce(m, client, spec.RunID, plannerName, starter, dest, maxRounds, maxFrames, cancel)

	report := farm.FinishReport{
		RunID:     spec.RunID,
		Reason:    reason,
		Detail:    detail,
		TraceTail: m.TraceTail(50),
	}
	if state, err := m.SaveState(); err == nil {
		report.SaveState = state
	} else {
		log.Printf("farm: run %s: save state for finish: %v", spec.RunID, err)
	}
	if err := client.Finish(context.Background(), report); err != nil {
		log.Printf("farm: run %s: finish: %v", spec.RunID, err)
	}
}

// heartbeatLoop pushes a heartbeat once a second until stopHeartbeat
// closes, closing cancel if the wall asks for a cooperative stop.
func heartbeatLoop(m *emu.Emu, client *farm.Client, runID string, cancel, stopHeartbeat chan struct{}) {
	ticker := time.NewTicker(time.Second)
	defer ticker.Stop()
	for {
		select {
		case <-stopHeartbeat:
			return
		case <-ticker.C:
			var mem state.Mem
			g := state.Read(m, &mem)
			reply, err := client.Heartbeat(context.Background(), farm.Heartbeat{
				RunID: runID,
				Frame: m.FrameCount(),
				Map:   mem.U8(sym.CurMap),
				X:     g.Player.X,
				Y:     g.Player.Y,
			})
			if err != nil {
				log.Printf("farm: run %s: heartbeat: %v", runID, err)
				continue
			}
			if reply.Cancel {
				select {
				case <-cancel:
				default:
					close(cancel)
				}
			}
		}
	}
}

// runSpecOnce drives one run to completion and reports why it stopped, in
// farm.FinishReport.Reason terms ("done"/"stuck"/"error"/"budget").
func runSpecOnce(m *emu.Emu, client *farm.Client, runID, plannerName, starter, dest string, maxRounds, maxFrames int, cancel chan struct{}) (reason, detail string) {
	if plannerName == "llm" {
		offered := []agent.Objective{
			{Kind: agent.KindStarter}, {Kind: agent.KindErrand},
			{Kind: agent.KindTrain, Level: 10}, {Kind: agent.KindHeal}, {Kind: agent.KindGym},
		}
		for _, name := range skill.PlaceNames() {
			offered = append(offered, agent.Objective{Kind: agent.KindGoTo, Place: name})
		}
		res := agent.Run(m, m.ROM(), agent.NewLLMPlanner(), offered, agent.Budget{
			MaxRounds: maxRounds, MaxFrames: maxFrames, Cancel: cancel,
		})
		if res.Err != nil {
			return "error", res.Err.Error()
		}
		return stopName(res.Stop), ""
	}

	which, ok := starterFromName(starter)
	if !ok {
		return "error", fmt.Sprintf("unknown starter %q", starter)
	}
	if err := skill.GetStarter(m, m.ROM(), which, skill.StatAwareMove(m.ROM())); err != nil {
		return "error", err.Error()
	}
	target, ok := skill.Place(dest)
	if !ok {
		return "error", fmt.Sprintf("unknown destination %q", dest)
	}
	if err := skill.GoTo(m, m.ROM(), target); err != nil {
		return "error", err.Error()
	}
	return "done", ""
}
```

```go
// cmd/pokewall/wall.go
package main

import (
	"encoding/json"
	"net/http"
	"strings"
	"sync"

	"github.com/maestroi/pokepilot/farm"
)

// tile is one leased run's last-known state, kept only in memory. A
// restart of pokewall loses tile history; dumps on the operator's volume
// (Task 7) are the durable record.
type tile struct {
	Spec   farm.Spec
	Status string // "leased" / "running" / "done" / "error" / "stuck" / "budget"
	Last   farm.Heartbeat
	Finish farm.FinishReport
}

// Wall is the orchestrator's whole state: a queue of specs waiting to be
// leased and a map of tiles for runs in flight or finished.
type Wall struct {
	mu     sync.Mutex
	queue  []farm.Spec
	tiles  map[string]*tile
}

func NewWall() *Wall {
	return &Wall{tiles: map[string]*tile{}}
}

// Enqueue adds a spec an operator wants run next. FIFO: the oldest
// enqueued spec is leased first.
func (w *Wall) Enqueue(spec farm.Spec) {
	w.mu.Lock()
	defer w.mu.Unlock()
	w.queue = append(w.queue, spec)
}

// TileStatus reports one run's last-known status, "" if unknown.
func (w *Wall) TileStatus(runID string) string {
	w.mu.Lock()
	defer w.mu.Unlock()
	t, ok := w.tiles[runID]
	if !ok {
		return ""
	}
	return t.Status
}

func (w *Wall) lease(rw http.ResponseWriter, r *http.Request) {
	w.mu.Lock()
	if len(w.queue) == 0 {
		w.mu.Unlock()
		rw.WriteHeader(http.StatusNoContent)
		return
	}
	spec := w.queue[0]
	w.queue = w.queue[1:]
	w.tiles[spec.RunID] = &tile{Spec: spec, Status: "leased"}
	w.mu.Unlock()

	rw.Header().Set("Content-Type", "application/json")
	json.NewEncoder(rw).Encode(spec)
}

func (w *Wall) heartbeat(rw http.ResponseWriter, r *http.Request, runID string) {
	var hb farm.Heartbeat
	if err := json.NewDecoder(r.Body).Decode(&hb); err != nil {
		http.Error(rw, err.Error(), http.StatusBadRequest)
		return
	}
	w.mu.Lock()
	t, ok := w.tiles[runID]
	if !ok {
		t = &tile{Spec: farm.Spec{RunID: runID}}
		w.tiles[runID] = t
	}
	t.Status = "running"
	t.Last = hb
	w.mu.Unlock()

	rw.Header().Set("Content-Type", "application/json")
	json.NewEncoder(rw).Encode(farm.HeartbeatReply{Cancel: false})
}

func (w *Wall) finish(rw http.ResponseWriter, r *http.Request, runID string) {
	var report farm.FinishReport
	if err := json.NewDecoder(r.Body).Decode(&report); err != nil {
		http.Error(rw, err.Error(), http.StatusBadRequest)
		return
	}
	w.mu.Lock()
	t, ok := w.tiles[runID]
	if !ok {
		t = &tile{Spec: farm.Spec{RunID: runID}}
		w.tiles[runID] = t
	}
	t.Status = report.Reason
	t.Finish = report
	w.mu.Unlock()

	rw.WriteHeader(http.StatusOK)
}

// Handler serves the lease/heartbeat/finish protocol plus a plain tile
// grid at "/". No framework: net/http's mux is enough for four routes.
func (w *Wall) Handler() http.Handler {
	mux := http.NewServeMux()
	mux.HandleFunc("POST /v1/lease", w.lease)
	mux.HandleFunc("POST /v1/runs/{id}/heartbeat", func(rw http.ResponseWriter, r *http.Request) {
		w.heartbeat(rw, r, r.PathValue("id"))
	})
	mux.HandleFunc("POST /v1/runs/{id}/finish", func(rw http.ResponseWriter, r *http.Request) {
		w.finish(rw, r, r.PathValue("id"))
	})
	mux.HandleFunc("GET /", w.serveGrid)
	return mux
}
```

`http.ServeMux` path parameters (`r.PathValue`) require Go 1.22+; `go.mod` already declares `go 1.26.0`, so no dependency is needed.
